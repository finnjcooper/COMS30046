# RISC-V SIMULATOR

Prerequisites
---

make, cmake  
gcc  
riscv64-unknown-elf-gcc (for compiling new benchmarks)

# Instructions

The program is built using make build files that are generated by cmake.
A makefile is included in the root directory to automate this process.

`make` will build the simulator.

`make bench` will build all benchmark ELFs from `bench/src`. This requires `riscv64-unknown-elf-gcc`.

New benchmark programs can be written and simulated by placing them in `bench/src` and building with `make bench`, then running the simulator with `make run BENCH=...`.

`make run BENCH=factorial` will build the simulator and run a benchmark ELF file from `bench/build`.

`make headless BENCH=factorial` will build and run the simulator without the TUI.

Terminal Interface
---

Once running, basic controls are shown in the bottom right corner:

`h` - show a popup with all controls.

`SPACE` / `ENTER` - advance the simulation once cycle.

`r` - run the simulation until the end of the program.

`TAB` - cycle between the register view and the stack view in the right-hand panel.  
Note that for now the stack only shows what is between the current stack pointer and the end of memory.

`q` - quit the simulator.
